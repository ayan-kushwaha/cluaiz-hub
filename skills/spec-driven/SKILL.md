# 📐 Spec-Driven Engineering Protocol

This skill ensures complex systems are thoroughly specified, architected, and validated before any source code modifications are executed.

## 📋 Spec Workflow
1. **Problem Definition:** Articulate the precise technical objective and scope boundaries.
2. **Tradeoff Analysis:** Evaluate alternatives, runtime constraints, and security implications.
3. **Component Contracts:** Define file paths, data structures, and function signatures.
4. **Verification Plan:** Outline exact automated test criteria and success conditions.
